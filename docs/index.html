Overview

Sekilas project

JIMNY COFFEE adalah sistem POS berbasis Laravel untuk kasir, admin, dan owner. Sistem ini menangani transaksi, stok, laporan, shift, izin, hingga integrasi QRIS.

Fokus utama

  • KasirTransaksi dan checkout
  • AdminMenu, stok, shift, akun
  • OwnerLaporan dan ringkasan bisnis
  • Smart AssistantInsight dan analytics

04

Setup dan operasional

Menjalankan project

composer install
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
npm install
npm run build
php artisan serve

Perhatian: Jalankan migration dan seeder hanya pada database lokal atau database pengujian yang memang disiapkan. Verifikasi konfigurasi .env terlebih dahulu. Jangan menjalankan seeder pada database operasional tanpa pemeriksaan dan backup.
