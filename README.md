## Project Overview

JIMNY COFFEE merupakan aplikasi Point of Sale berbasis Laravel untuk mendukung operasional kedai kopi melalui antarmuka khusus **Owner**, **Admin**, dan **Kasir**.

<div align="center">

<img src="docs/assets/jimny-coffee-brown-dashboard.png" alt="JIMNY COFFEE System Dashboard" width="100%" />

</div>

## Core Features

| Modul | Fungsi |
|---|---|
| Point of Sale | Pemesanan, transaksi, dan checkout kasir |
| Inventory | Pengelolaan menu, kategori, dan stok |
| Payments | Pembayaran tunai dan QRIS Midtrans |
| Reports | Riwayat transaksi dan laporan penjualan |
| Employee Management | Presensi, shift, dan pengajuan izin |
| Smart Assistant V2 | Ringkasan dan analitik penjualan |

**Catatan:** Analitik penjualan telah tersedia. Model prediksi machine learning belum diimplementasikan.

## Getting Started

Untuk menjalankan project secara lokal, siapkan PHP, Composer, Node.js, MySQL, dan environment Laravel seperti Laragon.

Panduan lengkap mencakup:

- Persyaratan sistem dan dependency
- Konfigurasi `.env` dan database
- Migration dan seeder untuk database pengembangan baru
- Setup pembayaran Midtrans Sandbox
- Menjalankan aplikasi dan pengujian QRIS
- Troubleshooting dan keamanan

**[Baca Panduan Instalasi Lengkap](docs/guides/README-LENGKAP.md#menjalankan-project)**

> Jalankan migration dan seeder hanya setelah memastikan koneksi database mengarah ke lingkungan pengembangan yang benar. Jangan menjalankan seeder pada database operasional tanpa pemeriksaan dan pencadangan.
